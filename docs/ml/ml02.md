# ML-02: Spatial PM2.5 Forecasting — PE-001 Pilot

## Overview

ML-02 evaluates two approaches to spatial PM2.5 forecasting using the PE-001 wildfire event:

- **Method A — Predict then interpolate:** Train XGBoost using monitor-local historical features, generate monitor-level predictions, then apply inverse-distance weighting (IDW).
- **Method B — Interpolate then predict:** Construct leave-one-monitor-out IDW historical PM2.5 lag features, then train XGBoost to predict PM2.5.

Both approaches are evaluated on matched forecast horizons using chronological evaluation within PE-001.

## Experimental Configuration

| Parameter | Value |
|---|---|
| Event | PE-001 |
| Dataset rows | 19,673 |
| Forecast monitors | 2 |
| IDW power | 2.0 |
| Maximum neighbors | 4 |
| Experimental radius | 100 km |
| Minimum neighbor distance | 1 km |
| Forecast horizons | 1, 3, 6, 12, 24 hours |

The serving contract specifies a 50 km interpolation radius, whereas this exploratory experiment uses 100 km.

The two PE-001 monitors are approximately 71 km apart. With a 50 km radius, neither station would be eligible as a neighbor of the other in leave-one-monitor-out evaluation.

Therefore, 100 km was retained as an explicit experimental override. These results should not be interpreted as validation of the 50 km production configuration.

## Method A vs. Method B Results

The following results come from the historical paired evaluation over a 14-day test window. Lower MAE and RMSE indicate better predictive accuracy.

| Horizon | N | MAE A | MAE B | RMSE A | RMSE B |
|---|---:|---:|---:|---:|---:|
| 1h | 608 | 5.323 | 5.908 | 7.860 | 8.581 |
| 3h | 608 | 6.012 | 6.178 | 8.783 | 9.093 |
| 6h | 608 | 6.494 | 6.443 | 9.521 | 9.409 |
| 12h | 608 | 6.448 | 6.598 | 9.526 | 9.598 |
| 24h | 612 | 6.310 | 6.296 | 9.358 | 9.410 |

Method A achieves lower MAE at 1h, 3h, and 12h; Method B achieves lower MAE at 6h and 24h.

These results do not establish general superiority of either method.

## Minimum-Distance Exclusion Verification

To reduce potential spatial leakage, the IDW feature implementation excludes neighboring monitors within 1 km of the forecast location, in addition to excluding the target monitor ID.

The updated implementation was evaluated against the original PE-001 v1.1 dataset.

- Original rows: 19,673
- Regenerated rows: 19,673
- Forecast keys identical: Yes
- Rows with changed PM2.5 lag features: **0**

The underlying PM2.5 source data contains 4,029 observations from two monitors approximately 71 km apart.

Consequently, the new 1 km exclusion does not alter any PE-001 lag features. The historical evaluation remains applicable to this distance-filter change.
